# macOS 状态栏指示器（v3.3.0）

录音、排队、重试的状态改为显示在 macOS 菜单栏图标上，取代了老的「在输入框里打 `0` / `1`」临时方案——那个方案会往你正在编辑的文本里插字符，很干扰。

## 实现

- 键盘状态同步到 `StatusBarController`：启动后跑一个守护线程监听键盘，主线程留在状态栏事件循环里。录音、排队、重试都会驱动状态栏更新。相关代码在 [main.py](../main.py) 和 [src/keyboard/listener.py](../src/keyboard/listener.py)。
- [src/ui/status_bar.py](../src/ui/status_bar.py)：状态栏控制器本体。支持从 `.env` 读取 `STATUS_ICON_*` 路径加载 PNG/PDF 图标，默认用 emoji。排队数量会附加在图标旁。

## 自定义图标

在 `.env` 里设置图标路径（配置示例见 [env.example](../env.example) 的「状态栏图标自定义」段）：

```bash
STATUS_ICON_IDLE=/绝对路径/assets/icons/idle.png
STATUS_ICON_RECORDING=/绝对路径/assets/icons/recording.png
STATUS_ICON_PROCESSING=/绝对路径/assets/icons/transcripting.png
STATUS_ICON_TEMPLATE=true
```

- 支持 PNG / PDF，建议 18×18 ~ 22×22 的模板 PDF
- `STATUS_ICON_TEMPLATE=true` 让 macOS 按系统主题自动着色（跟随深色/浅色模式）
- 未配置的状态回落到默认 emoji，所以可以只替换其中几个
- 想给更多状态配图标，继续加同名环境变量即可（如 `STATUS_ICON_RETRY`）
- 改完需要重启程序生效

## 已知限制

macOS 状态栏按钮无法直接叠加徽章，所以用自定义图片时，排队数量是作为按钮文本追加在图标旁边的（或只显示在 tooltip 里）。想要真正的描边/透明风格，用模板图并保持 `STATUS_ICON_TEMPLATE=true`。

## 使用提示

状态栏图标可以按住 ⌘（Command）拖动排序，和其它 macOS 原生状态栏项一致。拖不动的话，先用鼠标点住图标再按 ⌘。
